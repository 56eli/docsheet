# Decisions

Reviewed, owner-approved ruling records for the curated catalogue. These are
point-in-time decision documents: they explain *why* a batch of rows was
mapped, excluded, regrouped, or related the way it was. The current machine
state always lives in the CSV inputs under `data/` and is regenerated by the
build scripts — if a record here disagrees with generated output, the
generated output plus its declared CSV inputs win.
